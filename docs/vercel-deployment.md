# Deploy CreatorDNA web on Vercel

Vercel hosts **only the Vite frontend**. It does not run the persistent Express/WebSocket API, Redis/BullMQ worker, ffmpeg, or open-source model servers. Deploy those separately (the repo includes Cloud Run specs). Never configure `DEV_AUTH_BYPASS`, `AI_STUB_CLIENT` or `DEMO_MODE` in production.

1. Import this GitHub repository into Vercel. Set **Root Directory** to `apps/web`, Framework Preset **Vite**. Install Command: `cd ../.. && corepack pnpm install --frozen-lockfile`. The `apps/web/vercel.json` build command builds workspace dependencies from the repository root; output is `apps/web/dist`. Use Node 20 or newer.
2. Deploy the API and worker separately with Firebase, Redis and storage, and configure Firebase Auth authorized domains to include the Vercel hostname. The API's `CORS_ORIGINS` must contain the exact `https://YOUR-PROJECT.vercel.app` origin. Never put model API keys in Vercel's `VITE_` variables.
3. In Vercel project environment variables, set `VITE_API_URL=https://YOUR-API-DOMAIN` (without trailing slash), plus the `VITE_FIREBASE_*` public Firebase client settings from `apps/web/.env.example`. Redeploy after changing build-time variables. If using voice coaching/render progress, set `VITE_WS_ORIGIN=wss://YOUR-API-DOMAIN`; websocket access requires an API deployment that supports WebSocket upgrades. Otherwise render progress falls back to polling.
4. Optional text Arena: run an OpenAI-compatible inference server (vLLM, llama.cpp, etc.) reachable **from the API**, not from the browser. Set on the API: `ARENA_BASE_URL=https://YOUR-INFERENCE/v1`, `ARENA_TEXT_MODELS=model-a,model-b,model-c`, `ARENA_JUDGE_MODEL=judge-model`, and optional `ARENA_API_KEY`. This enables `/api/v1/arena/run` for hooks and scripts. For distinct server endpoints, a future registry is still needed. No models are downloaded by this repository; if the endpoint is unavailable, Arena generation fails explicitly.

The Vercel SPA rewrite does not proxy `/api` or `/ws`. Without the independently deployed backend, the frontend can build and display but cannot authenticate, generate content or render videos. Vercel preview domains need their own CORS and Firebase Auth allowlists. Verify `GET /health` on the API and a signed-in hook generation before inviting users.
